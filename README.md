# Tugas Flutter - Katalog Layanan

Aplikasi Flutter sederhana yang menampilkan katalog layanan IT dengan dua halaman — halaman daftar dan halaman detail.

## Fitur

- Halaman Beranda dengan daftar 3 katalog layanan
- Navigasi ke halaman detail menggunakan `Navigator.push`
- Halaman detail dengan fitur favorit dan pilih jumlah item
- Implementasi `StatelessWidget` dan `StatefulWidget`

## Cara Menjalankan

1. Clone repo ini
2. Jalankan `flutter pub get`
3. Jalankan ke emulator atau device dengan `flutter run`

## Struktur Folder

```
lib/
├── main.dart
├── models/
│   └── catalog_item.dart
└── screens/
    ├── home_screen.dart
    └── detail_screen.dart
```
